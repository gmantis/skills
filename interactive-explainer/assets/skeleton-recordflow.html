What the model assumes (REPLACE)
    
A model built from reading the graph, not a run of it. From the DAIS DML notes (dml/transform-rules.md, dml/nulls.md):

    
    
      
  • Lower priority numbers run first, an unprioritized rule runs last, and once a field has a value no later rule for it runs. A prioritized rule that returns NULL hands over to the next priority.
    • 
      
  • A concrete rule for a field takes it out of out.* :: in.*, so its fallback must be another concrete rule (a priority-2 out.* does not fill it).
    • 
      
  • String functions and arithmetic pass NULL through; first_defined(x, d) supplies a default.
    • 
      
  • If no rule gives a value, a nullable field becomes NULL; a non-nullable one makes the transform fail, and this error stops the graph by default.
    • 
    

    
Illustrative, not checked illustrative: the components keep going and send a failing record to the reject port (by default the graph would stop); an unconnected reject port discards the record; a lookup miss or a NULL key gives NULL; the inner join sends unmatched payments to unused0 and drops unmatched customers on the unconnected unused1; the rates, record formats and rounding.
