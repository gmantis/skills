Does the model do what it says?

How the model works

Scores. For each criterion, the options in play are scored by min–max: the best raw value gets 1, the worst 0, the rest in between (on log10 of the value for criteria marked "log scale", because they span orders of magnitude). "Lower is better" criteria are flipped. If every option has the same value, everyone gets 0.5, so the criterion cannot change the ranking.

Total. Weighted mean: Σ weight × score / Σ weight, between 0 and 1. Scores are relative to the options in play, so taking one out can change the others' scores and even the winner.

Sensitivity. The totals share one denominator, so the order is the order of Σ weight × score, which is linear in each weight. For the winner i and any rival j, moving weight c alone to w′ ties them at w′ = wc + (Ni − Nj) / (sjc − sic). The nearest such point either way is where first place flips; the page says it in words and checks it in the table above.
